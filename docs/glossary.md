# Glossary

Living vocabulary document for Owl.

| Term         | Meaning                                                                               |
| ------------ | ------------------------------------------------------------------------------------- |
| Beacon       | A browser request sent on page load and on a client-side address change.              |
| Bot          | A request from an automated client, or a request with no browser identity.            |
| Bounce       | A visit with one page that stayed under 15 seconds.                                   |
| Bucket       | The chart step for a range: an hour, a day, a month, or a year.                       |
| Country      | The country of a browser request.                                                     |
| Device Class | Desktop, mobile, or tablet.                                                           |
| Direct       | A visit with no referrer.                                                             |
| Duration     | How long one pageview lasted, in milliseconds.                                        |
| Operator     | The one person who can read the private numbers.                                      |
| Page         | The URL path, without the query string or fragment.                                   |
| Pageview     | One stored view of one page.                                                          |
| Range        | The window the numbers cover: last 24 hours, 7 days, 30 days, 12 months, or all time. |
| Read client  | Server code that returns totals, breakdowns, and charts from stored pageviews.        |
| Referrer     | The host name of the site a visit came from.                                          |
| Script       | The tag a site adds to record pageviews.                                              |
| Session      | A visit.                                                                              |
| Time on site | The length of a visit, from the first pageview to the last signal.                    |
| Visit        | The same visitor until 30 minutes pass with no new pageview.                          |
| Visitor      | One person, seen as the same network and browser.                                     |
| Visitor ID   | A one-way hash of the IP address, the browser identity, and a server secret.          |
| Website ID   | The public name on the script tag that identifies a site.                             |
