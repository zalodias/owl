# A small core metric set

Status: locked  
Date: 2026-09-26

Owl records pageviews, unique visitors, bounce rate, time on site, top pages, referrers, country, device class, and a series of visitors and pageviews over a chosen range.

Left out until that set is trustworthy: a realtime globe, visitor profiles, funnels, custom events, revenue, Core Web Vitals, city, browser, and operating system.

The shape is the useful middle of a product like visitors.now, kept small enough for one person to run.
